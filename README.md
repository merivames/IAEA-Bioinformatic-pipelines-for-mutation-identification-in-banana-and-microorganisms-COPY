# Bioinformatics workflows for gamma irradiation analysis

## Overview

This repository contains workflows and scripts for the analysis of genome sequencing data generated from gamma-irradiated bananas and beneficial microorganisms.

The repository includes workflows for:
- Long-read analysis (PacBio and ONT)
- Short-read Illumina analysis
- Genome assembly evaluation
- Read mapping and alignment QC
- Comparative genomics
- Coverage and structural variation analysis
- Candidate mutation discovery
- Microbial genome analysis

The complete tutorial and detailed interpretation of results are available in the Documentation section.
